Many families choose a baby's name from the nakshatra the Moon was in at birth. Each nakshatra has four quarters (padas), and each pada has a first-letter sound. The name starts with that sound.

## How to use this table
1. Find your baby's **janma nakshatra** and **pada** from the birth chart, which a priest or free horoscope tool can supply. See [how to find the rashi](/find-your-janma-rashi-moon-sign/).
2. Take the syllable for that pada.
3. Choose a meaningful name that begins with it.

## The 27 nakshatras
| Nakshatra | Syllables for padas 1 to 4 | Rashi |
|---|---|---|
| Ashwini | Chu, Che, Cho, La | Mesha |
| Bharani | Li, Lu, Le, Lo | Mesha |
| Krittika | A, I, U, E | Mesha, then Vrishabha |
| Rohini | O, Va, Vi, Vu | Vrishabha |
| Mrigashira | Ve, Vo, Ka, Ki | Vrishabha, then Mithuna |
| Ardra | Ku, Gha, Na, Chha | Mithuna |
| Punarvasu | Ke, Ko, Ha, Hi | Mithuna, then Karkataka |
| Pushya | Hu, He, Ho, Da | Karkataka |
| Ashlesha | Di, Du, De, Do | Karkataka |
| Magha | Ma, Mi, Mu, Me | Simha |
| Purva Phalguni | Mo, Ta, Ti, Tu | Simha |
| Uttara Phalguni | Te, To, Pa, Pi | Simha, then Kanya |
| Hasta | Pu, Sha, Na, Tha | Kanya |
| Chitra | Pe, Po, Ra, Ri | Kanya, then Tula |
| Swati | Ru, Re, Ro, Ta | Tula |
| Vishakha | Ti, Tu, Te, To | Tula, then Vrischika |
| Anuradha | Na, Ni, Nu, Ne | Vrischika |
| Jyeshtha | No, Ya, Yi, Yu | Vrischika |
| Mula | Ye, Yo, Bha, Bhi | Dhanu |
| Purva Ashadha | Bhu, Dha, Pha, Dha | Dhanu |
| Uttara Ashadha | Bhe, Bho, Ja, Ji | Dhanu, then Makara |
| Shravana | Ju, Je, Jo, Gha (some lists: Khi, Khu, Khe, Kho) | Makara |
| Dhanishta | Ga, Gi, Gu, Ge | Makara, then Kumbha |
| Shatabhisha | Go, Sa, Si, Su | Kumbha |
| Purva Bhadrapada | Se, So, Da, Di | Kumbha, then Meena |
| Uttara Bhadrapada | Du, Tha, Jha, Na | Meena |
| Revati | De, Do, Cha, Chi | Meena |

## Notes
- **Regional variations exist.** Some Telugu, Tamil and Kannada panchangams use slightly different syllables, especially for Shravana and Ardra. Ask your family priest.
- **Telugu spellings.** The syllables are given in Roman letters. In Telugu, for example, *Chu, Che, Cho, La* are చు, చే, చో, లా.
- **The name need not be the only one.** Many families keep a nakshatra name for ceremonies and a different everyday name.
- **Choose a good meaning.** The syllable is the start, and the meaning is what the child will carry.

*Traditions vary by family and region.*
